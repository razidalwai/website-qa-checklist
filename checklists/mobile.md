# Mobile Website QA Checklist

A checklist for testing e-commerce websites across mobile devices and screen sizes.

## Responsive Layout

- [ ] Website adapts correctly to different screen sizes
- [ ] No horizontal scrolling
- [ ] Content does not overflow containers
- [ ] Text is readable without zooming
- [ ] Images resize correctly
- [ ] Spacing and alignment are consistent

## Header & Navigation

- [ ] Mobile menu opens and closes correctly
- [ ] Logo displays correctly
- [ ] Search works on mobile
- [ ] Cart icon is visible and functional
- [ ] Account icon redirects correctly
- [ ] Menu links redirect to the correct pages

## Product Listing

- [ ] Product cards display correctly
- [ ] Product images are properly sized
- [ ] Filters open and close correctly
- [ ] Sorting works
- [ ] Product prices are clearly visible
- [ ] Pagination or Load More works

## Product Detail Page

- [ ] Product gallery supports swipe
- [ ] Images change correctly
- [ ] Product information is readable
- [ ] Variants and swatches are usable
- [ ] Add to Cart button is clearly visible
- [ ] Quantity selector works

## Cart & Checkout

- [ ] Cart layout displays correctly
- [ ] Quantity can be updated
- [ ] Checkout button is visible
- [ ] Forms are easy to complete
- [ ] Keyboard does not block important fields
- [ ] Payment options display correctly

## Footer

- [ ] Footer sections display correctly
- [ ] Footer links work
- [ ] Contact information is readable
- [ ] Social media links work

## Device Testing

- [ ] Tested on iPhone
- [ ] Tested on Android
- [ ] Tested in portrait orientation
- [ ] Tested in landscape orientation
- [ ] Tested on multiple screen sizes
