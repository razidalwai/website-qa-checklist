# SEO QA Checklist

A practical checklist for reviewing essential SEO elements before launching a website.

## Page Titles & Meta Descriptions

- [ ] Every important page has a unique title
- [ ] Meta descriptions are added
- [ ] Titles accurately describe the page content
- [ ] No duplicate titles
- [ ] No duplicate meta descriptions

## URLs

- [ ] URLs are short and descriptive
- [ ] URLs use readable words
- [ ] No unnecessary parameters
- [ ] Broken URLs redirect correctly
- [ ] HTTPS is enabled

## Headings & Content

- [ ] Each page has one clear H1
- [ ] H2 and H3 headings follow a logical structure
- [ ] Important pages contain useful content
- [ ] No placeholder or duplicate content
- [ ] Product descriptions display correctly

## Images

- [ ] Important images have descriptive alt text
- [ ] Image file sizes are optimized
- [ ] Images load correctly
- [ ] Image filenames are descriptive
- [ ] Images are responsive

## Internal Links

- [ ] Navigation links work
- [ ] Internal links point to the correct pages
- [ ] No broken internal links
- [ ] Breadcrumbs work correctly
- [ ] Important pages are accessible through navigation

## Technical SEO

- [ ] XML sitemap is available
- [ ] robots.txt is configured
- [ ] Canonical tags are implemented where required
- [ ] 404 page works correctly
- [ ] Redirects work correctly
- [ ] Pages intended for indexing are indexable

## Mobile & Performance

- [ ] Website is mobile-friendly
- [ ] Pages load within a reasonable time
- [ ] Layout remains stable while loading
- [ ] Images are appropriately optimized
- [ ] Important content works without errors

## Final SEO Review

- [ ] Homepage metadata checked
- [ ] Category metadata checked
- [ ] Product metadata checked
- [ ] Important landing pages checked
- [ ] Sitemap reviewed
- [ ] Broken links reviewed
