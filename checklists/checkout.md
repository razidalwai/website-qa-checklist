# Checkout QA Checklist

A practical checklist for testing the complete e-commerce checkout journey before launch.

## Cart

- [ ] Products can be added to the cart
- [ ] Correct product name and image are displayed
- [ ] Product variants display correctly
- [ ] Quantity can be increased or decreased
- [ ] Products can be removed
- [ ] Cart subtotal calculates correctly
- [ ] Cart remains saved after page refresh

## Discount Codes

- [ ] Valid discount codes are accepted
- [ ] Invalid discount codes show an error
- [ ] Discount amount calculates correctly
- [ ] Discount restrictions work correctly
- [ ] Multiple discount rules behave as expected

## Customer Information

- [ ] Guest checkout works
- [ ] Existing customers can log in
- [ ] Required fields are clearly marked
- [ ] Email validation works
- [ ] Phone number validation works
- [ ] Address fields work correctly

## Shipping

- [ ] Available shipping methods are displayed
- [ ] Shipping cost calculates correctly
- [ ] Free shipping rules work correctly
- [ ] Delivery information is accurate
- [ ] Unsupported locations are handled correctly

## Tax

- [ ] Tax is calculated correctly
- [ ] Tax amount is clearly displayed
- [ ] Order total includes applicable tax

## Payment

- [ ] Available payment methods are displayed
- [ ] Card payment flow works
- [ ] Payment errors display useful messages
- [ ] Failed payments do not create duplicate orders
- [ ] Successful payments redirect correctly

## Order Confirmation

- [ ] Order confirmation page displays
- [ ] Order number is generated
- [ ] Correct products appear in the order
- [ ] Final amount is correct
- [ ] Confirmation email is triggered
- [ ] Order appears in the customer account

## Final Checkout Test

- [ ] Desktop checkout tested
- [ ] Mobile checkout tested
- [ ] Guest checkout tested
- [ ] Registered customer checkout tested
- [ ] Successful payment tested
- [ ] Failed payment scenario tested
